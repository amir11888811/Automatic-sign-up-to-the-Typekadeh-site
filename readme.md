## Automatic login to the Typekadeh site
When we run this code, the system automatically opens the website, logs into the account, enters your Gmail, username, and password, and completes the registration.
### instruction

- first you write `cmd` in the Terminal
- for install venv you must write `python -m venv .venv` in Terminal.
- for active venv you must write `.venv\scripts\activate` in Terminal.
- and you must install the library:`(pip install requests) and (pip install selenium)`
- finally you must run the code `(python 1.py)`
